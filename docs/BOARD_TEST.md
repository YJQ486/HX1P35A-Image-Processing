# 上板测试

## 操作说明

|操作|效果|
|---|---|
|上电或下载|约数秒后出图，默认彩色模式、白平衡 A|
|短按模式键 B9|彩色 → 灰度 → 铅笔素描 → Sobel → 彩色|
|长按 B9 约 1 秒|白平衡 A → B → C → A，状态面板 `AWB` 行显示当前分支|
|按 C7|整个系统复位，恢复彩色模式和白平衡 A|

摄像头尽量对着光线均匀的方向，避免正对窗户。

## 验收清单

适用于最终版本 `sc520cs_sketch4_sram_20261102.bit`（SHA-256 `3F618308…`）。先核对 SHA-256，再执行 PROGRAM_SRAM，每一步录像。

|步骤|操作|通过标准|对应赛题|
|---|---|---|---|
|1|上电后不按键，观察 10 秒|彩色画面连续，没有撕裂、错位或花屏|基础 1、3|
|2|看右上角|安路 Logo 完整，透明区不遮挡画面|基础 4|
|3|看左上角|状态面板文字清楚|基础 4、进阶 1|
|4|短按 1 次|灰度画面|基础 2|
|5|再短按 1 次|铅笔素描：物体轮廓为黑色线条，暗处为灰色阴影，墙面等平坦区没有明显黑点|扩展 1|
|6|再短按 1 次|Sobel：物体边缘为白线，平坦区基本为黑|基础 2|
|7|再短按 1 次|回到彩色|进阶 1|
|8|长按约 1 秒，重复 3 次|`AWB` 行依次显示 A → B → C → A，画面颜色随之变化|进阶 5|
|9|红色物体在画面中移动|出现黄色框和 `RED TARGET`，框跟随物体|扩展 2、进阶 2|
|10|换成蓝色物体|出现天蓝色框和 `BLUE TARGET`，框跟随物体|扩展 2、进阶 2|
|11|物体移到画面边缘或移出|框不异常扩大，物体移出后框消失|扩展 2|
|12|摄像头在亮处和暗处之间转动|几秒内亮度自动调整|进阶 5|
|13|在四种模式下各按一次 C7|恢复为彩色、白平衡 A，画面正常|稳定性|
|14|连续运行 20～30 分钟，中途切换几次模式|不死机，不花屏|基础 3|

SRAM 全部通过后，由开发者手动执行 PROGRAM_FLASH 和 VERIFY_FLASH。断电至少 5 秒后重新上电，不按键，观察 30 秒，再快速检查步骤 4～7；至少重复 3 次。按 C7 后才恢复正常的，不算首次启动成功。

## 已知问题

### 启动后偶发闪烁

SRAM 下载或 Flash 冷启动后，偶尔出现整帧亮度逐帧跳变。按 C7 或重新插拔 HDMI 线后恢复，此后不再出现。

诊断版（`D25715A1`）在闪烁期间读取了视频通路的状态：进入 DDR 的每帧字数完整（`2A300` = 172,800 字），对齐器无故障，写 FIFO 无溢出，读 FIFO 无新增欠载。逐帧分析录像发现，FPGA 在 DDR 之后生成的固定颜色 OSD 背景也随画面一起变亮 1.14～1.61 倍，而显示器以外的区域不变。因此亮度变化发生在 OSD 叠加之后，即 HDMI 发送、链路或显示器一侧，与传感器和帧缓存无关。

已尝试开机 2 秒后自动复位 PLL 50 ms（`76A1E671`）和停发 TMDS 1.5 秒（`61FD7FE0`），都没有消除闪烁。根因未确定，作为偶发问题记录。**演示时上电后先观察几秒，出现闪烁就按 C7。**

### 逆光过曝

窗外光进入画面时，白衣、窗户等区域会过曝。原因是室内主体偏暗，AE 已把曝光和增益调到上限（状态面板 `REQ 07C7 G 00B0`），而 AE 采用室内主体优先策略，不会为了小块亮区压暗整个画面。如果改成高光优先，室内主体会更暗，所以未修改。

### 暗环境

暗室中物体之间的亮度差小，Sobel 幅值低于噪点门限 48 的弱边缘不会显示，素描和 Sobel 模式的线条会变少；红蓝目标也较难达到检测门限。提高环境照明后效果明显改善。

### 检测框滞后

检测结果在写入 DDR 之前得出，显示的却是从 DDR 读出的帧，两者没有按帧槽绑定。目标快速移动时，框可能比物体稍慢。检测只看颜色和区块密度，大面积红色或蓝色背景也可能被选中。
