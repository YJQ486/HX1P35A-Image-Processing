# 依赖与公开范围

公开仓库包含自研代码、模块测试、检查脚本和工程文档。完整视频工程还需要厂商提供的电路模块及工具资料，其中部分内容的公开分发许可尚未明确，因此保留在本地。

## 公开内容与复现范围

|内容|公开仓库中是否提供|用途|
|---|---|---|
|阶段基线自研 Verilog、测试和脚本|提供|阅读实现、校验公开文件、运行相应模块仿真|
|版本与依赖清单|提供|确定文件位置、大小和 SHA-256，核对版本|
|后续候选的功能说明和验证报告|提供|了解 Logo、红色检测及修复过程|
|完整厂商例程、生成 IP、加密代码和本地修订|未提供|完整构建需要；必须匹配对应版本的内容校验值|
|bitstream、原始视频、完整运行日志和备份|未提供|本地追溯和恢复，不是公开下载材料|

**公开模块测试可独立运行，完整摄像头工程不能仅依赖公开仓库复现。** 标注“本地证据”的路径用于原工作环境追溯，不表示对应文件已公开。

## 版本校验原则

同名文件可能对应不同版本。复核须同时确认文件来源、大小和 SHA-256 校验值，建立源码、测试及构建产物的对应关系。`release/current.json`、`active_sources.csv` 和 `dependencies.csv` 仍对应保留的 AWB 阶段基线，不会自动指向较新的检测候选。

恢复工程需同时满足材料使用权限和文件版本要求。先按下列清单确认内容，再执行本地检查；同名官方例程不能替代清单指定的本地修订。


## 未公开材料的依据

本地许可文件、README 和源文件头部中，尚未找到明确覆盖厂商文件、手册及衍生 bitstream 的公开分发授权。因此，厂商材料、包含厂商源码的补丁和完整编程镜像暂留本地；取得授权后再调整发布范围。

工具安装包、许可证、密钥、缓存、Runs 数据库和个人配置不在发布范围内。旧候选、原始视频及完整日志用于本地追溯。

公开文件通过 `.gitattributes` 保留原始字节，避免换行转换影响源文件哈希；历史发布检查曾逐项比较 Git blob 与工作区文件。

## 恢复完整工程

从安路比赛或开发板官方支持渠道获取 SC520CS Lab1、PH1P35 配套 IP、板级资料及 Tang Dynasty 6.2.168116；摄像头资料包括 SC520CS-03 数据手册 V1.6 和应用指南 V1.4，可向供应方获取。

AWB 阶段集成版本包含本地修订的顶层、ISP、AWB、复位与 CDC 逻辑及相机控制接线。官方原始例程与该阶段集成文件的哈希并不必然一致，旧 SC500CS 工程也不能替代该版本。恢复现有成果时，应使用整理前快照，或经授权取得清单对应的精确文件，然后执行：

```powershell
python scripts/verify_current.py --local
```

仅取得官方原始例程不足以复现当前 bitstream。完整构建的依赖和脚本限制见[构建说明](CURRENT_BUILD.md)。

## bitstream、视频与文件大小检查

AWB 阶段清单选定的 bitstream 为 1,789,539 字节。由于厂商 IP 的分发授权尚未明确，该文件未放入仓库或 Release，仓库仅保留来源、大小及 SHA-256。演示视频目前保留本地原件及观察记录。

2026-10-16 发布检查覆盖了最终文件清单和原有已跟踪文件，未包含超限文件。GitHub 对超过 50 MiB 的普通 Git 文件发出警告，超过 100 MiB 则拒绝接收，参见 [GitHub 大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。
