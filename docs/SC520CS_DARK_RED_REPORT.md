# SC520CS 暗红区域检测后继报告（2026-10-19）

暗红后继在稳定性修复版上仅将最低 R 门槛从 144 降至 96，用于检查较暗红区的召回。模块回归、工具构建和 bitstream 生成已完成；真实召回、误报和连续运行均为 `not tested`。2026-10-19 构建阶段未下载或写 Flash。

## 候选与改动

候选为 `qa/sc520cs_dark_red_trial_20261019`，本地说明见 `qa/sc520cs_dark_red_trial_20261019/RELEASE_DARK_RED.md`。除 R 最低门槛 144→96 外，AE/AWB、Logo、四模式、48 色差、64/48 密度门槛、160 区域支持量和 3 入/2 出迟滞均保持。

与 stable 相比，最终时序余量减小。36 条 Gray 路径仍使用 7.2 ns 预算，红色邮箱 34 个存活物理位仍使用 12 ns 预算，未放宽约束。

## 问题背景与证据边界

2026-10-19 分析的 45.433 秒视频显示 AWB A，AE 请求随场景变化，并非持续最大。REQ/DON 分别反映请求与事务完成，不能当作传感器实时读回。屏摄缺少源 RGB 和逐级计数，无法确定苹果是在颜色、密度还是区域支持量环节被排除。降低 R 门槛依据源码机制和受控刺激，没有从屏摄颜色拟合阈值。

验证采用原 stable 与暗红后继同输入对照、1280×720 区域参考模型和继承回归。以下数值来源于本地 `RELEASE_DARK_RED.md` 与 `dark_release_summary.json`，不表示本次重新执行。
