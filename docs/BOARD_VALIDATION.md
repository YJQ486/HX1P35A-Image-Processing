## 后续验证方法与记录要求

固定灯光、摄像头位置和显示器设置，记录正在使用的文件名、SHA-256 和白平衡分支。若无法核实文件指纹，明确写“未确认”。由板级测试负责人依次执行并记录：

1. 拍摄完整画面，检查摄像头输出、右上 Logo 和左上状态面板。
2. 短按依次切换彩色、灰度、二值化、Sobel 边缘检测、彩色；长按依次切换 A/B/C，每档至少等待 20 帧，建议 3 秒。
3. 红纸从中央移向四边和角落，部分移出再返回；加一个远处小红点，检查包围框是否异常扩展。记录误框、漏框和延迟。
4. 移走红纸、放入另一块红区，观察旧框消失与目标取舍。修复版允许短暂保留旧框，具体按[修复报告](SC520CS_RED_STABILITY_REPORT.md)的完整帧规则判断。
5. 有框时复位，确认视频恢复且旧框不沿用；复位后默认彩色/A，演示 C 时需重新选择。
6. 连续观察 20～30 分钟，记录开始、结束、异常时间和次数，保留原始视频或带时间的分段记录。

|记录项|填写内容|
|---|---|
|文件与硬件|文件名、SHA-256 或未确认；板卡、摄像头、供电、显示器|
|条件|灯光、摄像头位置、显示模式、A/B/C 分支|
|时间|开始、结束、总时长|
|现象|黑屏、花屏、滚屏、停住、漏框、误框；无异常时仍注明观察条件与覆盖范围|
|操作|切换与复位次数、每次结果|
|证据|原始视频、照片或现场记录路径|
|结论|通过/失败/未完成，以及未覆盖的项目|

截至 2026-10-19，现有记录未提供完整的长时间稳定性和最终验收结果，状态为 `not tested`。新增暗红后继候选的实物召回、误报及长期稳定性也未验证，见[暗红检测报告](SC520CS_DARK_RED_REPORT.md)。Flash 固化与脱离电脑的断电冷启动单独验收；复位恢复不能替代冷启动验证。以下保留 AWB 阶段观察与测试表，空白记录不视为完成。
