# 赛题对照

赛题：选题二“基于安路 FPGA 的实时数字图像处理系统”（《赛题解析二》第 5、6、23～26 页）。最终设计至少实现 3 条基础要求和 1 条扩展要求，所有功能集成在同一个镜像中，固化后上电即可运行。

“实现”指最终版本源码中具备该功能，并已通过仿真和构建检查；“上板”指在实物上看到的结果。两者分开记录，最终镜像的逐项上板验收见 [上板测试](BOARD_TEST.md)。

## 基础要求：4 条全部实现

|要求|实现|上板|
|---|---|---|
|1. MIPI 摄像头采集，HDMI 实时输出|SC520CS 双通道 MIPI → ISP → DDR2 帧缓存 → HDMI 1280×720|最终镜像能出图|
|2. 至少一种 FPGA 图像处理算法|灰度变换、Sobel 边缘检测|前序镜像有四模式实拍；最终镜像未逐项记录|
|3. 处理后的视频稳定输出，画面连续|已实现；启动时偶发闪烁，按 C7 恢复|最终镜像未记录连续运行；`617C457A` 登记连续运行 10 分钟正常|
|4. OSD 叠加，包含安路 Logo|左上角状态面板，右上角官方安路图形 Logo|Logo 数据经仿真和网表逐项核对；最终镜像未逐项记录|

赛题第 5 页把“边缘检测、灰度变换或二值化”列为算法示例，只需实现其中一种。最终版本用铅笔素描替换了二值化，灰度和 Sobel 仍满足要求 2。

## 扩展要求：2 条

|要求|实现|说明|
|---|---|---|
|1. 风格化处理或视觉增强|**铅笔素描**|由 Sobel 笔画和灰度阴影合成，去底量随亮度变化以抑制亮处噪点；2026-11-02 在暗室和补光条件下上板确认效果|
|2. 简单目标检测与识别，叠加结果和文字|**红、蓝色目标检测**|画出检测框，显示 `RED TARGET` / `BLUE TARGET`。按颜色和区块密度判断，不区分物体类别；暗环境下需要补光|
|3. 结合实际应用，外部控制|未实现||
|4. 提高实时性、降低资源|未单列|Logo ROM 移入 ERAM，节省约 1800 个 LUT；赛题第 26 页说明评测不依据资源大小|
|5. 自主创意|未单列||
